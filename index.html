Can you decode this message?


#include <stdio.h>

int main() {
    int numbers[] = {14, 7, 21, 20, 9, 8, 20, 8, 5, 14, 21, 20};
    printf("The scrambled number sequence is: ");
    for (int i = 0; i < 12; i++) {
        printf("%d ", numbers[i]);
    }
    printf("\nCan you decode it? What does it say?\n");
    return 0;
}

Hint: Convert the numbers back to letters (A=1, B=2, ..., Z=26).
